第 0 步：打开文件
────────────────────────────────────────────
1. 双击运行 D:\blender-5.2.1-windows-x64\blender.exe
2. 菜单 File > Open（文件 > 打开）
   选择本文件夹里的 yamato_edit.blend
3. 打开后你应该能看到：
   - 一个灰色头发、带兽耳的人物（持刀者）
   - 一把武士刀 + 刀鞘
   - 画面下方有一条"时间线"

────────────────────────────────────────────
第 2 步：先播放看看现在的动画
────────────────────────────────────────────
1. 鼠标移到 3D 视图上，按 空格键 开始/暂停播放
   （或点时间线上的 ▶ 按钮）
2. 用鼠标左键拖动时间线底部的绿色竖线，可以逐帧看
   现在动画的流程是：
   帧0     刀鞘在腰侧
   帧19-78 整把刀横放到身前
   帧79-96 刀竖直拔出（阎魔变体）
   帧101-119 转回来横放在眼前
   帧121-185 弧形轨迹收回刀鞘
3. 按数字键盘 1（正前方）、3（右侧）、7（俯视）
   切换视角，方便看清

────────────────────────────────────────────
第 3 步：核心概念（只要懂这个就会改动画）
────────────────────────────────────────────
动画 = 一连串"姿势照片"（关键帧）
- 你在"第 20 帧"把刀摆到位置A，按 I 拍照
- 你在"第 60 帧"把刀摆到位置B，按 I 拍照
- Blender 自动把 A→B 之间的动作补出来（过渡）

所以改动画 = 改这些"照片"的位置/旋转，或删掉不要的照片。

────────────────────────────────────────────
第 4 步：必会操作（抄这张表）
────────────────────────────────────────────
操作                        按键
──────────────────────────────────────────
选中骨架（先做这个）        点击 3D 视图里的 Bladeholder_arm
进入姿态模式              按 Tab 键（或左上角模式下拉选"姿态"）
选中刀/鞘骨骼            鼠标左键点 hardpointA（刀）
                                点 hardpointB（鞘）
                                按住 Shift 再点 = 两个一起选
移动                      选中后按 G，再移动鼠标，左键确定
旋转                      选中后按 R，再移动鼠标，左键确定
精确移动/旋转              G 后按 X/Y/Z 锁轴，或直接输入数字
插入关键帧（拍照）        摆好姿势后按 I，选"LocRot"（位置+旋转）
删掉一个关键帧            选中骨骼，按 I，选"清除所有关键帧"
撤销                      Ctrl+Z
切换到下一个/上一个关键帧  左箭头/右箭头（需选中骨骼）

【提醒】每次"拍照"前，一定要先选中刀或鞘的骨骼！
       刀=hardpointA   鞘=hardpointB

────────────────────────────────────────────
第 5 步：动手改（你要的阎魔动作，一步步来）
────────────────────────────────────────────
说明：以下帧号是建议值，你可以自己微调。
先全部学会，改完一次再播放看效果。

【5.1 让刀+鞘从第 1 帧就竖立】
 1. 拖时间线到 帧0
 2. 点 3D 视图里的 Bladeholder_arm，按 Tab 进姿态模式
 3. 按住 Shift 点选 hardpointA（刀）和 hardpointB（鞘）
 4. 按 R 旋转，让"刀+鞘"整体竖起来（刀尖朝上）
    （对着正前方视图转，转到刀身竖直即可）
 5. 按 I → 选 LocRot（拍照）
 → 现在第 0 帧刀鞘就是竖立的了

【5.2 拔出刀】
 1. 拖到 帧30
 2. 只选中 hardpointA（刀）【Shift 点一下刀取消鞘的选择】
 3. 按 G 沿刀鞘口方向向上移动，让刀从鞘里抽出一半
 4. 按 I → LocRot 拍照
 5. 拖到 帧50
 6. 再按 G 把刀完全抽出来（竖在鞘上方一点）
 7. 按 I → LocRot 拍照

【5.3 刀鞘放回去】
 1. 拖到 帧50（接着上一步）
 2. 只选中 hardpointB（鞘）
 3. 把它移动/旋转回腰侧（第 0 帧时鞘的位置）
    ——最快方法：拖时间线回 帧0，记住鞘的位置和角度；
      再拖回 帧50，选中鞘，把它摆回那个位置
 4. 按 I → LocRot 拍照

【5.4 刀横放身前，从左缓慢移到右】
 1. 拖到 帧60
 2. 只选中 hardpointA（刀）
 3. 按 R 旋转，把刀横放（水平，刀尖朝左或朝右都行）
 4. 按 G 把刀放到身前左侧位置
 5. 按 I → LocRot 拍照
 6. 拖到 帧75（中间过渡帧）
 7. 按 G 把刀移到身前中间，按 I → LocRot 拍照
 8. 拖到 帧90
 9. 按 G 把刀移到身前右侧，按 I → LocRot 拍照
 → 播放看看：刀在身前从左慢慢滑到右

【5.5 顺势向前劈砍】
 1. 拖到 帧100
 2. 选中 hardpointA（刀）
 3. 按 R 旋转让刀向前挥（刀刃朝前，做一个劈的动作）
 4. 按 G 把刀往前（朝玩家前方远处）移一点
 5. 按 I → LocRot 拍照

【5.6 收刀（刀尖插回鞘里）】
 1. 拖到 帧120
 2. 选中 hardpointA（刀）
 3. 旋转+移动，把刀转到鞘口方向（刀刃朝上、刀尖朝鞘口）
 4. 按 I → LocRot 拍照（开始往回走的过渡）
 5. 拖到 帧160
 6. 把刀移到鞘口正上方，刀尖对准鞘口，慢慢往里
 7. 按 I → LocRot 拍照
 8. 拖到 帧180
 9. 把刀完全插进鞘里（刀和鞘重合）
 10. 按 I → LocRot 拍照
 → 播放看看：刀从劈砍位沿弧形轨迹收回来插进鞘里

【5.7 收尾归位】
 1. 拖到 帧202
 2. 同时选中刀和鞘，摆回第 0 帧的初始位置（腰侧）
 3. 按 I → LocRot 拍照

────────────────────────────────────────────
第 6 步：保存文件
────────────────────────────────────────────
File > Save（Ctrl+S）保存到本文件夹，改名存个新文件
（比如 yamato_edit_v2.blend），别覆盖原件。

────────────────────────────────────────────
第 7 步：导出成游戏能用的动画文件（.vmd）
────────────────────────────────────────────
1. 点 3D 视图里的 Bladeholder_arm（骨架）
2. 菜单 File > Export > MikuMikuDance Motion (.vmd)
3. 弹出窗口右侧"骨架"栏：
   - Scale：**填 12.5**（重要！必须填 12.5，不能填 0.08。
     这是 mmd_tools 的特性：导入填 0.08，导出要填它的倒数 12.5，
     否则导出的动画位置会缩小 0.08×0.08 倍，刀会消失）
   - 导出骨骼：选"所选对象（选中对象）"
4. 起个文件名（比如 inspect_yamato.vmd），点 Export
5. 导出的文件就是游戏里的动画文件

常见问题
────────────────────────────────────────────
Q：改完播放，刀飞出去了？
A：忘了插关键帧。每摆完一个姿势必须按 I → LocRot 拍照。
Q：选不中骨骼？
A：先点 Bladeholder_arm，按 Tab 进入姿态模式；
   骨骼名字显示在 3D 视图里（或在大纲里点 hardpointA）。
Q：镜头里看不到刀了？
A：按数字键盘 1 回正面，或按 ~（波浪键）选视角。
Q：改乱了想重来？
A：用备份文件重新打开：a_edit.blend / yamato_edit.blend
   原件我放在本文件夹，改乱了随时重新复制一份。
Q：还是不会/想偷懒？
