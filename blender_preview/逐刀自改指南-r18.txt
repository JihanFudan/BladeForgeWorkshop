2) 音效时间轴（Java 数组，每把刀一个）
   src\main\java\cn\blockforge\generated\slashbladereshslashblad\
   InspectComboStates.java
     YAMATO_CUES     阎魔 = 你自己改的时间轴
                     5握鞘/19顶出/32出鞘/40拔刀/65握鞘/85握鞘/
                     126回旋/151回旋/185收鞘
     GENERIC_CUES    通用（重新编排：20握鞘/32出鞘/40拔刀/85挥砍/
                     119回旋/150回旋/185收鞘）
     WOOD_CUES       木刀（独立数组，默认同通用）
     BAMBOO_CUES     竹刀（独立数组，默认同通用）
     MURAMASA_CUES   村正（独立数组，默认同通用）
     FOX_BLACK_CUES  黑狐（独立数组，默认同通用）
     FOX_WHITE_CUES  白狐（独立数组，默认同通用）
   改法：帧号 = 动画第几帧，Cue = 音效类型。想改某把刀的某个
   音效时机，直接改对应数组里的数字即可。Cue 类型见下：
     HOLD 握鞘 / NUDGE 顶出 / SHED 出鞘摩擦 / DRAW 拔刀 /
     SLASH 挥砍 / SPIN 旋转 / SHEATHE 收鞘

3) 音效音频文件（ogg，当前共用三套音色）
   src\main\resources\assets\slashbladeresh_slashblad\sounds\
     金属（村正/黑狐/白狐/阎魔/通用共用）：
       draw.ogg 拔刀 / quickly_draw.ogg 快拔 / spin.ogg 旋转 /
       shed_sheath.ogg 出鞘摩擦 / hold.ogg 握鞘
     木质（木刀）：draw_wood / knock_wood / spin_wood / hold_wood
     竹质（竹刀）：draw_bamboo / knock_bamboo / spin_bamboo / hold_bamboo
   给某把刀单独音色的做法（以村正为例）：
     ① 复制 draw.ogg 改名为 draw_muramasa.ogg，放进上面目录
     ② 在 sounds.json 里加一组 "draw_muramasa"
     ③ 在 InspectSounds.java 里把村正的音效引用换成新 SoundEvent
     ④ 重新构建
   不想动代码的话，最简单：直接替换现有的 draw.ogg 等文件，
   所有金属刀一起变。

三、用 Blender 改某把刀的动画
----------------------------------------------------------------
工具：D:\blender-5.2.1-windows-x64\blender.exe（已装 mmd_tools）
改装配（已含刀/鞘模型 + 人物，可直接导入 VMD 修改）：
   C:\Users\JihanFudan\Desktop\mod\blender_preview\yamato_edit.blend（阎魔）
   C:\Users\JihanFudan\Desktop\mod\blender_preview\a_edit.blend（通用/其他刀）
步骤：
  1. 打开 a_edit.blend（改木刀就用它，改完导出为 inspect_wood.vmd）
  2. 导入 VMD：File > Import > MMD Motion(.vmd)，
     选 combostate 目录里对应文件（如 inspect_wood.vmd）
  3. 选骨骼 → G 移动 / R 旋转 → I 选 LocRot 拍关键帧
  4. 导出：File > Export > MMD Motion(.vmd)
     保存到 combostate 目录，文件名务必保持 inspect_wood.vmd 等原名
     ⚠ 导出时 Scale 必须填 12.5（导入是 0.08，导出要乘回去），
       否则动画位置会缩小 156 倍，刀会贴脸不动。
  5. 重新构建（见下）
